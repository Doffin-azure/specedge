# Evaluation inputs

[c4_prompts.example.json](c4_prompts.example.json) contains a small sample for inspecting the input format. For the full C4 benchmark, obtain the input from the [upstream supplementary repository](https://github.com/kaist-ina/specedge/tree/main/data), then place it at `data/c4_prompts.json` locally. The repository ignores that path.
